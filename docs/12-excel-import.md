# 12. نظام الاستيراد من Excel

## 12.1 الأنواع المدعومة

| النوع | الحقول الإجبارية | حقول اختيارية | ماذا يُنشئ |
|-------|------------------|---------------|------------|
| **الطلاب** | اسم الطالب، الصف، اسم ولي الأمر، هاتف ولي الأمر | الرقم المدرسي، رقم الطالب، الشعبة، الجنس، تاريخ الميلاد، الرقم الوطني، هاتف 2، العنوان، الحالة، ملاحظات | طالب + ولي أمر (أو ربط بولي أمر موجود بنفس الهاتف) + تسجيل في السنة المختارة |
| **المعلمات** / **الموظفون** | الاسم | الرقم الوظيفي، الهاتف، الوظيفة، القسم، تاريخ التوظيف، نوع الراتب، الراتب الأساسي، سعر الساعة الإضافية، البنك، رقم الحساب، ملاحظات | موظف (المعلمات يُعلَّمن كمعلمات تلقائيًا) |
| **أرصدة الطلاب** | الطالب (رقم الطالب أو الرقم المدرسي أو الاسم)، الرصيد | التاريخ، ملاحظات | رصيد مدين: ذمة «رصيد سابق» / رصيد دائن: رصيد دائن افتتاحي — مع قيودهما |
| **الذمم** | الطالب، نوع الذمة، المبلغ | التاريخ، الخصم (مبلغ أو نسبة)، عدد الأقساط، تاريخ أول قسط، ملاحظات | ذمة + أقساط + خصم + القيود |
| **الأقساط** | الطالب، نوع الذمة، رقم القسط، تاريخ الاستحقاق، المبلغ | المدفوع مسبقًا | صفوف نفس الطالب ونوع الذمة تُجمع في **ذمة واحدة بجدول أقساطها** كما هو في النظام القديم |
| **الموردون** | اسم المورد | النوع، الهاتف، مسؤول التواصل، العنوان، الرصيد الافتتاحي، ملاحظات | مورد (+ فاتورة رصيد افتتاحي) |
| **المصروفات** | التاريخ، التصنيف، المبلغ | المستفيد، البيان، طريقة الدفع، الصندوق | سند صرف من نوع مصروف + القيد |
| **سندات القبض** | التاريخ، الطالب، المبلغ | طريقة الدفع، الرقم القديم، البيان، الصندوق | سند قبض يوزع تلقائيًا على مستحقات الطالب |
| **سندات الصرف** | التاريخ، المستفيد، التصنيف، المبلغ | طريقة الدفع، الرقم القديم، البيان، الصندوق | سند صرف + القيد |

## 12.2 الخطوات (معالج من 5 خطوات)

```mermaid
flowchart LR
    A[1. اختيار النوع<br/>وتنزيل القالب] --> B[2. رفع الملف<br/>xlsx / xls / csv]
    B --> C[3. ربط الأعمدة<br/>عمود Excel ← حقل النظام]
    C --> D[4. المعاينة والتحقق<br/>أخطاء، ناقص، مكرر]
    D --> E[5. التأكيد والاستيراد<br/>+ تقرير النتيجة]
```

1. **اختيار النوع** + زر «تنزيل القالب الجاهز» (ملف Excel بأعمدة عربية، صف مثال، ورقة تعليمات تشرح كل عمود وقيمه المسموحة، وقوائم الصفوف وأنواع الذمم الحالية).
2. **رفع الملف**: يُقرأ على الخادم (بحد أقصى 10MB و 10,000 صف)، ويُحفظ مؤقتًا في جلسة استيراد باسم المستخدم.
3. **ربط الأعمدة**: النظام يربط تلقائيًا بمطابقة الأسماء (عربي وإنجليزي ومرادفات: «Student Name» / «اسم الطالب» / «الاسم» ← اسم الطالب)، والمستخدم يعدّل أي ربط من قائمة منسدلة. تظهر أول 10 صفوف كمعاينة مباشرة.
4. **المعاينة والتحقق**: كل صف يُفحص ويأخذ حالة:
   - ✅ **صالح**
   - ⚠️ **مكرر**: داخل الملف نفسه، أو موجود مسبقًا في النظام (مثل نفس الطالب ونفس هاتف ولي الأمر، أو نفس الرقم المدرسي)
   - ❌ **خطأ**: حقل إجباري ناقص، رقم غير صالح، تاريخ غير مفهوم، صف غير موجود، نوع ذمة غير معروف، طالب غير موجود...
   - مع رسالة عربية دقيقة لكل خطأ ورقم الصف في Excel، وإمكانية تنزيل تقرير الأخطاء كملف Excel لتصحيحه.
   - خيارات: تجاهل المكرر (الافتراضي) أو تحديث البيانات الموجودة (للطلاب والموظفين والموردين فقط)، وإنشاء الصفوف/الشعب غير الموجودة تلقائيًا.
5. **التأكيد**: لا يحدث أي استيراد قبل الضغط على «تأكيد الاستيراد». يُستورد كل الصالح داخل معاملة واحدة (إما الكل أو لا شيء)، مع رقم دفعة استيراد يُحفظ على كل سجل مُنشأ، وسجل نشاط بالملخص.

## 12.3 تنظيف القيم تلقائيًا

| المدخل | يتحول إلى |
|--------|----------|
| `١٥٠٠` أو `1,500` أو `1500.00` | 1500 |
| `05/09/2026` أو `2026-09-05` أو تاريخ Excel الرقمي | 2026-09-05 (الصيغة اليومية dd/mm/yyyy هي الافتراضية) |
| `+970 599-123-456` | `0599123456` (حسب رمز الدولة في الإعدادات) |
| `نعم` / `Yes` / `1` / `✓` | صحيح |
| `ذكر` / `M` / `Male` | ذكر |
| مسافات زائدة وأحرف مخفية | تُزال |
| «الصف الخامس» / «خامس» / «5» | يُطابق مع الصف الموجود بالاسم أو الترتيب |

## 12.4 الأمان

- الاستيراد يتطلب صلاحية `import.excel` + صلاحية إنشاء النوع المستورد.
- الملف يُقرأ كبيانات فقط (لا تُنفذ أي صيغ أو ماكرو)، والقيم النصية تُعامل كنص عادي.
- جلسات الاستيراد غير المكتملة تُحذف بعد 24 ساعة.
