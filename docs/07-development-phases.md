# 7. ترتيب مراحل التطوير

كل مرحلة تُسلَّم **مكتملة ومربوطة فعليًا بقاعدة البيانات** مع اختبارات للمنطق المالي، ولا تنتقل للمرحلة التالية قبل أن تعمل السابقة.

| المرحلة | المحتوى | المخرجات |
|---------|---------|----------|
| **0. الأساس** | إعداد المشروع، قاعدة البيانات، مكونات الواجهة RTL، التخطيط (القائمة والشريط العلوي)، تسجيل الدخول والجلسات والقفل، الصلاحيات، سجل النشاط، الإعدادات، الترقيم، المحرك المحاسبي، دليل الحسابات الافتراضي، البيانات الأولية | يمكن الدخول برؤية لوحة فارغة، وكل البنية التحتية جاهزة ومختبرة |
| **1. الطلاب** | السنوات الدراسية، المراحل والصفوف والشعب، أولياء الأمور (العائلات)، الطلاب، التسجيل السنوي، البحث، ملف الطالب | إدارة كاملة للطلاب والعائلات |
| **2. الذمم والأقساط والخصومات** | تصنيفات الذمم، الرسوم المقررة، إضافة ذمة مع التقسيط، الخصومات بنطاقاتها، إعادة الجدولة، الإلغاء، الذمم الجماعية، الخصومات الدائمة | حساب مالي صحيح لكل طالب |
| **3. القبض** | الصناديق والبنوك (الأساس)، سند القبض، الدفع السريع والتوزيع، الدفعة العائلية، الرصيد الدائن، الإلغاء، الشيكات، المرتجع، الطباعة الرسمية مع التفقيط، كشف حساب الطالب | دورة التحصيل كاملة |
| **4. الصرف والخزينة** | سند الصرف بأنواعه، تصنيفات المصروفات والإيرادات، الإيرادات الأخرى، الموردون وفواتيرهم، العمال والمقاولون وأعمالهم، التحويلات، كشوف الصناديق والبنوك، المرفقات | دورة الصرف كاملة |
| **5. الموظفون والرواتب** | الموظفون والمعلمات، الساعات الإضافية، السلف، مسير الرواتب (احتساب، اعتماد، صرف)، قسيمة الراتب | دورة الرواتب كاملة |
| **6. لوحة التحكم والتنبيهات والبحث** | البطاقات والرسوم، مركز التنبيهات، البحث السريع | رؤية الوضع المالي خلال ثوانٍ |
| **7. التقارير والتصدير** | محرك التقارير، الـ 23 تقريرًا، التصدير Excel/CSV/PDF/طباعة | مركز تقارير كامل |
| **8. الاستيراد من Excel** | القوالب، الرفع، ربط الأعمدة، المعاينة، اكتشاف الأخطاء والتكرار، التأكيد | ترحيل البيانات من الأنظمة القديمة |
| **9. الإدارة** | المستخدمون والأدوار والصلاحيات، الشركاء، عارض سجل النشاط ومحاولات الدخول | تحكم كامل بالوصول |
| **10. السنوات والترحيل** | إغلاق السنة، إعادة الفتح، ترحيل الطلاب | دورة السنة الدراسية |
| **11. النسخ الاحتياطي** | يدوي، تلقائي مجدول، تشفير، تنزيل، استعادة آمنة | حماية البيانات |
| **12. المحاسبة العامة** | دليل الحسابات، القيود اليدوية، الأستاذ، ميزان المراجعة، قائمة الدخل، الميزانية، فحص السلامة | بنية محاسبية مكشوفة للمحاسب |
| **13. التحصين والنشر** | ترويسات الأمان، اختبارات شاملة، Docker، دليل التشغيل | جاهز للإنتاج |

## الاختبارات المرافقة لكل مرحلة

- **اختبارات وحدة**: المبالغ والتقريب، تقسيم الأقساط، التفقيط، تطبيع النص العربي، حساب الراتب.
- **اختبارات تكامل** (على قاعدة بيانات اختبار حقيقية): كل عملية مالية تُنتج القيود الصحيحة، الإلغاء يعيد الأرصدة، الترقيم متسلسل تحت التزامن، ميزان المراجعة متوازن دائمًا، رصيد ذمم الطلاب في الأستاذ = مجموع أرصدة الطلاب.
