# 6. تصميم تجربة الاستخدام (UX Design)

## 6.1 المبادئ

1. **البساطة أهم من كثرة العناصر**: كل صفحة تجيب عن سؤال واحد، وتعرض زرًا رئيسيًا واحدًا واضحًا.
2. **يعرف المستخدم ماذا يفعل فورًا**: عنوان + وصف قصير + زر كبير (مثل «+ إضافة طالب»، «+ سند قبض جديد»، «احتساب رواتب الشهر»).
3. **العملية البسيطة في مكان واحد**: تسجيل الدفعة، إضافة ذمة، إضافة خصم كلها نوافذ من داخل ملف الطالب دون التنقل بين صفحات.
4. **لغة بسيطة**: «ذمة» بدل «مدين»، «دفعة» بدل «تحصيل»، ومع كل مصطلح محاسبي ضروري تلميح يشرحه (مثلًا: *مدين = ما على الطالب*، *دائن = ما دفعه الطالب أو خُصم له*).
5. **الأخطاء تمنع مبكرًا**: التحقق أثناء الكتابة، رسائل عربية واضحة تشرح ما المطلوب، تأكيد قبل أي عملية لا يمكن التراجع عنها.
6. **السرعة**: بحث فوري `Ctrl+K`، اختيار الطالب بالكتابة، توزيع تلقائي للدفعات، إدخال جماعي للذمم، حفظ بالضغط على Enter.

## 6.2 الهوية البصرية

| العنصر | القيمة |
|--------|-------|
| الاتجاه | عربي RTL بالكامل (`dir="rtl"`) |
| الخط | **IBM Plex Sans Arabic** — واضح ومريح للأرقام والجداول |
| حجم الخط الأساسي | 15px للنصوص، 14px للجداول، 24–28px للأرقام الكبيرة في البطاقات |
| اللون الأساسي | أخضر مزرق هادئ (Teal) — يوحي بالثقة والهدوء |
| الخلفية | رمادي فاتح جدًا، والبطاقات بيضاء بحدود ناعمة وزوايا دائرية |
| ألوان الحالات | أخضر = مدفوع، كهرماني = مدفوع جزئيًا / مستحق، أحمر = متأخر، أزرق = غير مستحق بعد، رمادي = ملغي |
| الأرقام | أرقام لاتينية (0-9) بفواصل الآلاف `12,500.00` ومحاذاة ثابتة العرض في الجداول |
| الأزرار | ارتفاع كبير (40–44px)، نص واضح + أيقونة، الزر الرئيسي ملوّن والثانوي بإطار |

## 6.3 هيكل الشاشة

```
┌──────────────────────────────────────────────────────────────┬────────────┐
│ [بحث سريع Ctrl+K........]   [السنة 2026/2027 ▾]  🔔3   👤 أحمد │            │
├──────────────────────────────────────────────────────────────┤  الشعار    │
│                                                              │ ────────── │
│  عنوان الصفحة                               [+ الزر الرئيسي] │ 🏠 الرئيسية │
│  وصف قصير لما تفعله هذه الصفحة                                │ 🎓 الطلاب   │
│                                                              │ 📄 الذمم    │
│  ┌──────── فلاتر وبحث ─────────────────────────────────────┐ │ ⬇ القبض    │
│  └─────────────────────────────────────────────────────────┘ │ ⬆ الصرف    │
│                                                              │ 👥 الموظفون │
│  ┌──────── المحتوى (جدول / بطاقات / تبويبات) ─────────────┐ │ 💰 الرواتب  │
│  │                                                         │ │ 🔨 العمال   │
│  │                                                         │ │ 🚚 الموردون │
│  └─────────────────────────────────────────────────────────┘ │ ...        │
└──────────────────────────────────────────────────────────────┴────────────┘
```

- **القائمة الجانبية (يمين)** بالترتيب المطلوب: الرئيسية، الطلاب، الذمم والأقساط، القبض، الصرف، الموظفون والمعلمات، الرواتب، العمال والمقاولون، الموردون، المصروفات، الإيرادات، الصندوق والبنوك، التقارير، استيراد Excel، المستخدمون والصلاحيات، الإعدادات. (وتظهر «المحاسبة العامة» و«سجل النشاط» لمن يملك صلاحيتها.)
- على التابلت: القائمة تصغر إلى أيقونات أو تُفتح كدرج جانبي بزر ☰.
- **الشريط العلوي**: البحث السريع، مبدّل السنة الدراسية، جرس التنبيهات بعدّاد، قائمة المستخدم.

## 6.4 الصفحات المحورية

### لوحة التحكم
- الصف الأول (أهم 4 أرقام): المتبقي على الطلاب، المحصل هذا الشهر، الأقساط المتأخرة، رصيد الصندوق.
- الصف الثاني: المطلوب من الطلاب، المحصل، المستحق هذا الشهر، عدد الطلاب المدينين، المصروفات، الرواتب، القبض، الصرف، رصيد البنوك، صافي الحركة.
- رسم أعمدة: التحصيل مقابل المصروفات لكل شهر في السنة.
- رسم: توزيع المصروفات حسب التصنيف، ونسبة التحصيل حسب الصف.
- قائمة التنبيهات، وآخر السندات.

### ملف الطالب
```
┌─────────────────────────────────────────────────────────────────────┐
│ محمد أحمد علي            الصف الخامس - أ   رقم: 00125   [تسجيل دفعة] │
│ ولي الأمر: أحمد علي 0599xxxxxx             [+ ذمة] [+ خصم] [⋯]      │
├──────────────┬──────────────┬──────────────┬──────────────┬─────────┤
│ إجمالي الذمم │ المدفوع      │ الخصومات     │ المتبقي      │ متأخر   │
│ 5,300.00     │ 2,400.00     │ 500.00       │ 2,400.00     │ 600.00  │
├─────────────────────────────────────────────────────────────────────┤
│ نظرة عامة | الذمم | الأقساط | الدفعات | سندات القبض | كشف الحساب | المرفقات │
└─────────────────────────────────────────────────────────────────────┘
```

### نافذة تسجيل دفعة
1. حقل **المبلغ** كبير في الأعلى (التركيز عليه تلقائيًا).
2. جدول المستحقات المفتوحة مع خانة «يُدفع الآن» لكل قسط، يُعبأ تلقائيًا من الأقدم، وقابل للتعديل.
3. سطر ملخص: الموزع / المتبقي كرصيد دائن.
4. طريقة الدفع (أزرار كبيرة قابلة للنقر) + الصندوق/البنك + التاريخ + بيانات الشيك عند الحاجة.
5. زر «حفظ وطباعة السند».

### نموذج إضافة ذمة
معاينة حية بجانب النموذج: المبلغ ← الخصم ← المبلغ النهائي ← جدول الأقساط.

### مسير الرواتب
جدول يشبه Excel: صف لكل موظف والأعمدة القابلة للتعديل مميزة بلون، والإجماليات تُحسب لحظيًا، وشريط سفلي ثابت فيه الإجمالي وزر «اعتماد».

## 6.5 المكونات الموحدة

| المكوّن | الاستخدام |
|---------|----------|
| رأس الصفحة PageHeader | عنوان + وصف + أزرار |
| بطاقة رقم StatCard | رقم كبير + عنوان + مقارنة/تلميح |
| جدول DataTable | ترقيم صفحات، فرز، رأس ثابت، صف إجماليات، حالة فارغة مع إرشاد |
| شارة الحالة StatusBadge | ألوان ثابتة لكل حالة في كل النظام |
| حقل المبلغ MoneyInput | فواصل آلاف تلقائية، يقبل الأرقام العربية ٠-٩ ويحوّلها |
| اختيار الطالب StudentPicker | بحث بالاسم/الرقم/الهاتف مع عرض الصف والمتبقي |
| نافذة التأكيد ConfirmDialog | للعمليات الحساسة، مع حقل «السبب» الإجباري للإلغاء |
| إشعارات Toast | نجاح/خطأ بعد كل عملية |
| الحالة الفارغة EmptyState | رسالة + زر للخطوة التالية (مثل: «لا يوجد طلاب بعد — أضف طالبًا أو استورد من Excel») |

## 6.6 الطباعة

- سند القبض والصرف: مقاس A5 أفقي أو نصف A4، شعار المدرسة واسمها وبياناتها، رقم السند والتاريخ، المبلغ رقمًا و**كتابةً** (فقط ألف وخمسمائة شيكل لا غير)، البيان، طريقة الدفع، التوقيعات (المستلم/المحاسب)، وختم «ملغي» إذا أُلغي.
- كشف الحساب والتقارير: A4 بترويسة المدرسة، الفترة والفلاتر، التاريخ والمستخدم الذي استخرجه، وترقيم الصفحات.

## 6.7 إمكانية الوصول والتجاوب

- تباين ألوان كافٍ، حجم نقر لا يقل عن 40px، التنقل بلوحة المفاتيح، تسميات لكل الحقول.
- التخطيط يعمل على الكمبيوتر (1280px+) والتابلت (768px+)؛ الجداول العريضة تتمرر أفقيًا داخل إطارها.
