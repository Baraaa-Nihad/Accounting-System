## المبادئ الحاكمة

1. **الدقة المحاسبية أولًا**: كل عملية مالية تُنشئ قيدًا محاسبيًا متوازنًا (مدين = دائن) داخل نفس معاملة قاعدة البيانات، ولا يمكن حفظ عملية بدون قيدها.
2. **لا حذف للحركات المالية**: الإلغاء يتم بقيد عكسي مع حفظ السند الأصلي بحالة «ملغي» وسبب الإلغاء ومن ألغاه ومتى.
3. **البساطة في الواجهة**: المستخدم يرى «ذمة، دفعة، سند قبض، سند صرف»، بينما يعمل المحرك المحاسبي في الخلفية.
4. **كل شيء مربوط فعليًا بقاعدة البيانات**: لا توجد أرقام وهمية أو صفحات شكلية؛ كل رقم في لوحة التحكم والتقارير محسوب من البيانات المحفوظة.
5. **الأمان وعدم التلاعب**: صلاحيات دقيقة، سجل نشاط غير قابل للتعديل، ترقيم متسلسل بلا فجوات، قفل السنوات المغلقة.
