# 8. الحالات الاستثنائية (Edge Cases)

## 8.1 الدفعات والأقساط

| الحالة | سلوك النظام |
|--------|-------------|
| دفع جزئي لقسط (500، دفع 300) | القسط «مدفوع جزئيًا»: المدفوع 300، المتبقي 200 |
| دفع أكبر من القسط الحالي | الفائض يُوزع تلقائيًا على الأقساط التالية بالترتيب (دفع مبكر) |
| دفع أكبر من كل المستحقات | الفائض يُسجل **رصيدًا دائنًا** للطالب بعد تأكيد صريح من المستخدم |
| دفعة لعدة ذمم (كتب + زي + قسط) | توزيع يدوي أو تلقائي داخل **سند واحد** |
| مستخدمان يسجلان دفعة لنفس القسط في نفس اللحظة | قفل صفوف الأقساط `FOR UPDATE` داخل المعاملة؛ الثانية تُعاد حساباتها ولا يمكن تجاوز المتبقي |
| إلغاء سند قبض بعد دفعات لاحقة | الأقساط تعود حسب التوزيعات الفعلية للسند الملغي فقط |
| سند قبض بتاريخ في سنة مغلقة | مرفوض برسالة واضحة |
| إلغاء سند من سنة مغلقة | يُسمح بقيد عكسي بتاريخ اليوم (فترة مفتوحة) مع تحذير |
| شيك مرتجع | إلغاء السند تلقائيًا بسبب «شيك مرتجع» وإعادة المبالغ على الطالب |
| مبلغ صفر أو سالب | مرفوض على مستوى الواجهة والخادم وقيود القاعدة |
| إدخال أرقام عربية (١٢٣) أو فواصل (1,500) | تُحوَّل تلقائيًا إلى رقم صحيح |

## 8.2 الذمم والخصومات

| الحالة | سلوك النظام |
|--------|-------------|
| مبلغ لا يقبل القسمة (1000 ÷ 3) | 333.33 + 333.33 + 333.34 (الفرق لآخر قسط) |
| يوم الاستحقاق 31 وشهر فبراير | آخر يوم في الشهر (28 أو 29) |
| إضافة نفس الذمة مرتين (جماعيًا) | الطالب الذي لديه نفس النوع في نفس السنة يُستثنى ويُعرض في المعاينة |
| خصم بعد دفع جزء من الأقساط | يُعاد توزيع الخصم على الأقساط غير المدفوعة فقط |
| خصم أكبر من المتبقي غير المدفوع | مرفوض مع توضيح المتبقي الممكن خصمه |
| خصم 100% | مسموح إذا لم يُدفع شيء؛ الأقساط تُلغى تلقائيًا |
| عدة خصومات على نفس الذمة | كل خصم بالنسبة يُحسب على المبلغ الأصلي، والمجموع لا يتجاوز المتبقي |
| إلغاء خصم | يعود المبلغ للأقساط غير المدفوعة، بقيد عكسي |
| إلغاء ذمة عليها دفعات | الدفعات تتحول لرصيد دائن للطالب (مع عرض ذلك قبل التأكيد) |
| تعديل مبلغ ذمة عليها دفعات | غير مسموح مباشرة؛ يُستخدم الخصم أو الإلغاء أو ذمة إضافية (لحماية سلامة الحسابات) |
| نوع ذمة مستخدم ويراد حذفه | لا يُحذف بل يُعطّل (يختفي من القوائم الجديدة ويبقى في السجلات) |

## 8.3 الطلاب والعائلات

| الحالة | سلوك النظام |
|--------|-------------|
| طالب بنفس الاسم وهاتف ولي الأمر | تحذير تكرار قبل الحفظ |
| رقم مدرسي مكرر | مرفوض (قيد تفرد) |
| إخوة بنفس هاتف ولي الأمر | اقتراح ربطهم بحساب عائلة واحد |
| دفعة عائلية مع ابن منسحب عليه ذمم | يظهر ضمن التوزيع مع شارة حالته |
| انسحاب الطالب منتصف السنة | خيار إلغاء الأقساط غير المستحقة بعد تاريخ الانسحاب |
| حذف طالب له حركات مالية | غير مسموح؛ تغيير الحالة فقط. الحذف متاح فقط لطالب بلا أي حركات |
| ترحيل طالب لديه تسجيل في السنة الهدف | يُتجاوز ويُعرض في النتيجة |
| الصف الأخير عند الترحيل | يُقترح «تخرج» تلقائيًا |

## 8.4 الرواتب والسلف

| الحالة | سلوك النظام |
|--------|-------------|
| مسير ثانٍ لنفس الشهر | مرفوض |
| موظف عُيّن منتصف الشهر | تعديل أيام العمل في المسير (الحساب نسبي) |
| قسط السلفة أكبر من صافي الراتب | يُخفض القسط تلقائيًا للمتاح ويبقى الباقي للأشهر القادمة |
| تعديل راتب الموظف بعد إنشاء المسودة | زر «إعادة الاحتساب» يحدّث المسودة |
| إلغاء مسير معتمد | مسموح فقط إذا لم يُصرف منه شيء؛ بقيد عكسي وتعود الساعات الإضافية والسلف معلّقة |
| صرف جزئي لراتب | مسموح؛ المتبقي يبقى مستحقًا للموظف |
| موظف غير فعال | لا يدخل في المسيرات الجديدة ويبقى تاريخه محفوظًا |

## 8.5 الخزينة والصرف

| الحالة | سلوك النظام |
|--------|-------------|
| صرف أو تحويل أكبر من رصيد الصندوق | مرفوض مع عرض الرصيد المتاح |
| تحويل من الحساب لنفسه | مرفوض |
| دفعة لمقاول أكبر من المتبقي | مرفوضة حتى يُعدّل مبلغ الاتفاق (بتسجيل نشاط) |
| تعطيل صندوق عليه رصيد | مرفوض حتى يُحوَّل رصيده |
| سند صرف بدون مرفق فاتورة | مسموح (المرفق اختياري) مع إمكانية الإرفاق لاحقًا |

## 8.6 السنوات والترقيم والنظام

| الحالة | سلوك النظام |
|--------|-------------|
| تاريخ لا يقع ضمن أي سنة دراسية معرفة | رسالة تطلب إنشاء السنة من الإعدادات |
| سندات بتاريخ السنة الميلادية الجديدة | الترقيم يبدأ من 000001 للسنة الجديدة (REC-2027-000001) |
| فشل حفظ سند بعد حجز رقمه | المعاملة كلها تُلغى بما فيها زيادة العداد، فلا تنشأ فجوة |
| انتهاء الجلسة أثناء إدخال نموذج | رسالة «انتهت الجلسة» وإعادة توجيه للدخول |
| تعديل نفس السجل من مستخدمين | التحقق من وقت آخر تعديل؛ الثاني يُطلب منه إعادة التحميل |
| ملف مرفق كبير أو بنوع غير مسموح | مرفوض (الحد 10MB؛ صور و PDF فقط) |
| استعادة نسخة احتياطية | نسخة أمان تلقائية قبل الاستعادة + تأكيد بكلمة المرور |
| محاولة الوصول لصفحة بدون صلاحية | رسالة منع + تسجيل |
| المنطقة الزمنية | «اليوم» حسب توقيت المدرسة وليس توقيت الخادم |
